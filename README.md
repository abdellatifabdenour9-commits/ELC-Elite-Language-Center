# Elite Language Center

A React + Vite website for Elite Language Center, using local images and a modern frontend stack.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the app in your browser at:
   ```
   http://localhost:3000/
   ```

## Build for Production

```bash
npm run build
```
